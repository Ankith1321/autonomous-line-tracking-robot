═════════════════════════════════════════════════════════════════════════════════
                           🐛 TROUBLESHOOTING QUICK FIXES
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: Demo doesn't start
SOLUTION:
  /ws/stop_final_demo.sh
  sleep 2
  ps aux | grep -E 'gazebo|ros2|python' | grep -v grep
  pkill -9 gzserver gzclient python3  # If needed
  /ws/run_final_demo.sh

PROBLEM: Robot doesn't move
SOLUTION:
  Check logs: tail -20 /ws/logs/autonomy_line.log
  Check topics: ros2 topic hz /camera/image_raw
  Restart: /ws/stop_final_demo.sh && /ws/run_final_demo.sh

PROBLEM: Line not detected
SOLUTION:
  Check HSV parameters in /ws/run_final_demo.sh
  View /line_mask in RViz (should show white line on black)
  Adjust hsv_lower_h, hsv_upper_h if line not visible

PROBLEM: Robot collides with obstacle
SOLUTION:
  Check logs: tail -20 /ws/logs/safety_obstacle.log
  May need to increase avoid_distance parameter
  See PRODUCTION_README.md for parameter tuning guide
